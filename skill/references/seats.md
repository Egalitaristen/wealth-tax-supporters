# Offices, seats and the Seats tab

This file holds section 6.7a of the skill. `skill/SKILL.md` keeps the section numbers as pointers to this file, so a reference such as "SKILL.md 6.7a" still finds it. Section numbers in the text below refer to the same numbering.

### 6.7a Offices, seats and the Seats tab
Every politician gets a row in **positions.csv** for each office they hold or held (columns in section 5), pointing at a **bodies.csv** row. State senators, councillors and MSPs are structured too, not only national legislators. A body with `seat_view=y` has its seats by party in **seats.csv** and gets a **Seats** tab on the country page: one dot per seat, lit where a supporter sits today.
- When you add a politician, add the position: the body, the party, the seat (`geo_unit_id`) and the `start` date from the source you found them in. Add a body row first if it is not there yet.
- `current=y` needs `checked`: the date the person was found on the body's own official list. Only those light a seat. `current=n` carries the `end` date; `current` blank means not checked against an official list (stays dark).
- A person who leaves a chamber loses the seat, never the evidence: set `current=n` and `end`, update `role` and `status=former_role` on the actor. Refreshing is how outdated tags go away.
- Seats tab only for chambers with an official, machine-readable member list: take the seat counts and the sitting members from it (UK: `skill/scripts/seats_uk.py data/gb`, which reads the Parliament Members API; US: `skill/scripts/seats_us.py data/us`, which reads the congress-legislators files; each rebuilds the chambers' seats and positions and prints every supporter whose role or status disagrees with the list; `skill/scripts/seats.py` does the same for any country that has an adapter in its `ADAPTERS` table (the list is the `ADAPTERS` table at the bottom of `seats.py`; running it for a country with no adapter prints it; Belgium, India's Rajya Sabha and Malaysia refuse scripts and are read once in a browser and passed with `--local`, see their guides; Indonesia, Nigeria and China are published seat totals read by hand with no member named, flagged where a figure is out of date). To add a country, write one adapter function that reads the parliament's open member list and returns its chamber(s), the sitting members and, where the source has them, former members with end dates. Read what the script prints before committing: a name-only match and a "not on today's list" can be a spelling difference as well as a real departure). Do not type seat counts from memory. Run it again after each election, by-election and run that adds politicians.
- Unlit seats mean nothing found yet, never opposition. Never add rows for members who are not supporters.
