# Uruguay (data/uy)

- **Geography:** the 19 departamentos (intendencias) are loaded as the local tier, with OCHA P-codes `UY01` to `UY19` from the [HDX COD-AB Uruguay 2020 gazetteer](https://data.humdata.org/dataset/cod-ab-ury) (CC BY-IGO). The 125 municipios are not loaded: that dataset has no municipios, only 204 second-level areas named "n.a2" and so on. Map: `ury_admbnda_adm1_2020.shp` with `topo_to_boundaries.py --project lonlat --scale 100 --simplify 0.2 --name-prop ADM1_ES --code-prop ADM1_PCODE`, and the ADM0 outline merged as `regions` with `merge_boundaries.py`.
- **Seats:** `python skill/scripts/seats.py data/uy --fix-status --local URL=FILE ...` reads the Parlamento's own *Integración* lists (tab Actuantes: the members who sit today, a substitute counting for the titular; the Vice President who presides is not one of the 30 senators). `parlamento.gub.uy` answers scripts with a CloudFront 403, so read each list once in a browser from the site itself and save what it returns: on `https://parlamento.gub.uy/camarasycomisiones/senadores/plenario/integracion` run `await (await fetch('/camarasycomisiones/senadores/plenario/integracion/json')).text()` (the page's *Descargar JSON* link adds a query string that the server refuses; the bare path works), and the same on `.../representantes/plenario/integracion` with `/representantes/plenario/integracion/json`. Each is a JSON list of `{Cuerpo, Cargo, Nombres (Surname, Given), Lema, Sustituciones}`. Save them as two files and pass `--local https://parlamento.gub.uy/camarasycomisiones/senadores/plenario/integracion/json=<senate file> --local https://parlamento.gub.uy/camarasycomisiones/representantes/plenario/integracion/json=<deputies file>`. Expect 31 and 99 rows (30 senators plus the presiding member). The Chrome tool that read it on 15 November 2026 could not POST to a localhost receiver without the local-network prompt, so the rows were copied out as text (name and party only; the substitution notes are not used).
- **Sources that work:** montevideo.com.uy, ambito.com, elobservador.com.uy (the quote is in the page text although the article is for subscribers) and the PIT-CNT site. The Wikipedia page of a legislator gives the department of a past term only.
- **Wikidata:** `match_wikidata.py` has an entry for `UY`.
