# Colombia (data/co)

- **Seats**: `python skill/scripts/seats.py data/co` reads two sources. The Cámara de Representantes (183 seats, 2026-2030) comes from the chamber's own page, https://www.camara.gov.co/representantes, which embeds a JSON object of members by department with their party (181 of the 183 were named on 28 October 2026; the rest show as Vacant). The Senado de la República (103 seats: 102 elected on 8 March 2026 and one for the runner-up of the presidential election, if in opposition) comes from a news list of the senators elected (Valora Analitik), because https://www.senado.gov.co/index.php/el-senado/senadores still shows the 2022-2026 senators. **Replace the Senate source with the Senate's own list as soon as its page shows the new period**, and run the adapter again. The next elections are in March 2030.
- **Names**: Colombian names carry two surnames and the register often keeps one, so the adapter uses strict matching (`strict=True`: a shared first and last word is not enough) and a deny list for a namesake (Miguel Ángel Pinto of the Liberal Party is not Miguel Ángel Pinto Rueda of the Centro Democrático). Read the "matched by name only" lines it prints.
- **Places**: put each representative in their department (the register currently has legislators at the country root); senators sit for the whole country, except the two indigenous seats.
