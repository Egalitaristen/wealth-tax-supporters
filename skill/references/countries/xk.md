# Kosovo research guide

No register yet: two research passes found no qualifying supporter, so `data/xk` was not added (leads below). Code `xk` is not ISO 3166-1 (pycountry has no entry, so `numeric_for` in build_site.py would return blank: no world-map shape; no `site/vendor/flags/xk.svg`).

Geography when it starts: 38 municipalities (geoBoundaries gbOpen XKX ADM2 lists them, licensed CC BY-SA 2.0 from OpenStreetMap, so not usable for a map); the Kosovo Agency of Statistics code list and the seven districts are still to load.

Terms: tatim mbi pasurinë (wealth), tatim në pronë (property: excluded), tatim progresiv (income scale), the Tax Administration's "Wealthy Persons" project (compliance, not a tax), the Vetëvendosje unjustified-wealth bill (illicit enrichment). Vetëvendosje's short programme, point 70, commits to a progressive system by income and wealth, no wealth tax named. AAK's 2025 programme has a progressive income tax; PDK's pledges to repeal the property tax law.
