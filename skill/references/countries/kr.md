# South Korea (data/kr)

- **Seats**: `python skill/scripts/seats.py data/kr` reads the member search of the National Assembly's open-information portal: a POST to `https://open.assembly.go.kr/portal/assm/search/searchAssmMemberSch.do` (the call its public search page makes, with `rows=400&page=1`) returns all current members in one response (299 of the 300 seats on 28 October 2026; the missing seat shows as Vacant). The portal's documented open API (`.../openapi/nwvrqwxyaytdsfvhu`) returns only five rows without a key, so it is not used. Ministers who keep their seat, as Korean law allows (Chung Dong-young, Unification Minister), are on the list. Read only the name, party and constituency; the service also returns age, phone, e-mail and staff, which must never go in the register. The next general election is in April 2028.
- **Names**: the register keeps the Hangul in the name (`Chung Dong-young (정동영)`) and the adapter matches on it. Hangul names collide (김종민 is both a 2020 Minjung Party candidate and a sitting independent member), so the adapter has a deny list (`fuzzy_deny`) for namesakes: add to it when a match prints for someone who is plainly not the same person.
